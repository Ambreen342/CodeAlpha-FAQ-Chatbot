# CodeAlpha FAQ Chatbot

A machine-learning-based FAQ chatbot developed during my CodeAlpha Artificial Intelligence Internship.

## Features

- FAQ question matching
- Text preprocessing
- TF-IDF vectorization
- Cosine similarity
- Interactive chatbot interface

## Technologies

- Python
- Scikit-learn
- TF-IDF
- Cosine Similarity
- Streamlit

## How to Run

```bash
pip install -r requirements.txt
streamlit run web_app.py
